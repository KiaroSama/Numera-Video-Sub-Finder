# Issue tracking

This is a solo repository with no external issue publication authorized for the current implementation. The integrated change and its review are tracked in the repository's GitHub pull request when one is required; public issues are not auto-created. Project terminology lives in root CONTEXT.md and architecture/testing contracts in docs/.

The implementation handoff leaves pull request merge and closure to an authorized reviewer. Required exact-source CI must finish before review acceptance; green CPU checks do not replace release qualification.
