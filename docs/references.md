# Primary references and provenance

Reviewed 2026-10-13; maintenance/language/native-loader sources refreshed 2026-10-15, version precedence/download bounds/decoder-drain sources refreshed 2026-10-16. UI/icon/contrast and tensor-replay sources refreshed 2026-10-17. These sources establish API/provenance decisions, not product test results.

- [Tauri 2 resource resolution](https://v2.tauri.app/develop/resources/) and [configuration](https://v2.tauri.app/reference/config/): native GUI/resource/sidecar packaging, scoped commands and generated glue.
- [Leptos](https://book.leptos.dev/) and [controlled form properties](https://book.leptos.dev/view/05_forms.html): Rust CSR frontend and reactive controls; DOM checkbox changes alone do not prove asynchronous preference persistence.
- [FFmpeg subtitle/ASS filters](https://ffmpeg.org/ffmpeg-filters.html#ass) and [frozen Noto fonts](https://github.com/google/fonts/tree/1d0e46c7933245c8180fe83e47917961c913bbdb/ofl): explicit shaped fonts for tiny synthetic script-integration fixtures. Original OFL1.1 notices accompany downloaded fonts; no real-subtitle accuracy claim follows from these fixtures.
- [SemVer precedence](https://semver.org/#spec-item-10) and [semver 1.0.28 comparator](https://docs.rs/semver/1.0.28/semver/struct.Version.html#method.cmp_precedence): metadata-only differences do not make a newer release.
- [Reqwest blocking timeouts](https://docs.rs/reqwest/0.13.5/reqwest/blocking/struct.ClientBuilder.html#method.timeout): per-operation I/O bounds supplement an explicit transfer deadline and cancellation checks.
- [FFmpeg send/receive state machine](https://ffmpeg.org/doxygen/trunk/group__lavc__encdec.html) and [target-native error constants](https://docs.rs/ffmpeg-next/9.0.0/ffmpeg_next/util/error/index.html): need-more-input is platform EAGAIN, never a hardcoded Linux errno.
- [Tauri updater](https://v2.tauri.app/plugin/updater/) and [updater 2.14.0 source](https://docs.rs/tauri-plugin-updater/2.14.0/tauri_plugin_updater/): signed-version verification, native format/install constraints and explicit consent. Bounded owned transfers and signed metadata supplement the plugin, not platform signing.
- [tessdata_best frozen catalog](https://github.com/tesseract-ocr/tessdata_best/tree/e12c65a915945e4c28e237a9b52bc4a8f39a0cec) and [Tesseract model compatibility](https://tesseract-ocr.github.io/tessdoc/Data-Files-in-different-versions.html): 123 regular language/vertical variants, LSTM mode and immutable pack provenance.
- [Rust cdylib](https://doc.rust-lang.org/reference/linkage.html), [libloading 0.9](https://docs.rs/libloading/0.9.0/libloading/) and [Linux loader](https://man7.org/linux/man-pages/man8/ld.so.8.html): explicit retained native-library ownership, borrowed synchronous ABI and relocated dependency closure.
- [Tauri application lifecycle](https://github.com/tauri-apps/tauri/blob/tauri-v2.12.4/crates/tauri/src/app.rs) and [WebDriver compatibility correction](https://github.com/Choochmeque/tauri-plugin-webdriver/commit/50e7509073ca47dbf2f42a965d8161c198b96ac3): setup registers application state during Ready; test-only Windows COM bindings must share framework type identities.
- [Clang-cl](https://clang.llvm.org/docs/UsersManual.html#clang-cl), [Windows LLD](https://lld.llvm.org/windows_support.html) and [Cargo target linker](https://doc.rust-lang.org/cargo/reference/config.html#targettriplelinker): explicit native LLVM tools with the existing MSVC ABI/SDK, not a process-leak exemption.
- [PowerShell environment-provider semantics](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_environment_variables?view=powershell-7.6): provider null removes a process variable, whereas the .NET method can create a present-empty value; isolation must restore both presence and value.
- [FFmpeg native executable probe](https://github.com/zmwangx/rust-ffmpeg-sys/blob/ba293c6ffa4a5f2f745df024c96b54b5c94abd84/build.rs#L900-L919), [Clang MSVC linker selection](https://github.com/llvm/llvm-project/blob/llvmorg-22.1.8/clang/lib/Driver/ToolChains/MSVC.cpp) and [scoped unused-argument markers](https://github.com/llvm/llvm-project/blob/llvmorg-22.1.8/clang/test/Driver/diagnostics.c): Cargo's linker setting does not control a C compiler driver's independent executable probe. These contracts support a candidate correction, not proven attribution of a surviving process.
- [Trunk0.21.14 tool selection](https://github.com/trunk-rs/trunk/blob/v0.21.14/src/tools.rs), [wasm-bindgen CLI](https://rustwasm.github.io/docs/wasm-bindgen/reference/cli.html) and [Binaryen133](https://github.com/WebAssembly/binaryen/releases/tag/version_133): matching native helper versions and verified Windows ARM64 optimizer admission; not cross-architecture emulation.
- [ort rc.14 tensor extraction](https://github.com/pykeio/ort/blob/1ee1f842e8a381153ede7a506f01734e545854e0/src/value/impl_tensor/extract.rs), [FFmpeg9.0.2 scaling](https://github.com/FFmpeg/FFmpeg/blob/n9.0.2/doc/scaler.texi) and [image0.25.10 buffers](https://github.com/image-rs/image/blob/v0.25.10/src/images/buffer.rs): borrowed tensor observation and active RGB comparison for generated-fixture diagnosis, not a recognition fix or accuracy claim.
- [Cargo1.99 release profiles](https://doc.rust-lang.org/1.99.0/cargo/reference/profiles.html) and [build timing reports](https://doc.rust-lang.org/cargo/reference/timings.html): compiler-stage evidence while preserving production optimization and ownership deadlines.
- [GitHub reusable workflows](https://docs.github.com/en/actions/how-tos/reuse-automations/reuse-workflows): a manual root with same-source reusable verification lanes.
- [FFmpeg](https://ffmpeg.org/documentation.html), [ffmpeg-next 9](https://docs.rs/ffmpeg-next/9.0.0/ffmpeg_next/) and [pinned vcpkg source](https://github.com/microsoft/vcpkg/tree/e456309491fd875487bf02b8a0dca76c1b1b00cc): source PTS/decode ownership and target-native builds.
- [ort](https://github.com/pykeio/ort) and [ONNX Runtime 1.31](https://github.com/microsoft/onnxruntime/releases/tag/v1.31.0): explicit environment/session/provider contracts. Exact ort RC is an intentional approved pin, not a stable release claim.
- [Tesseract](https://github.com/tesseract-ocr/tesseract), [5.5.3 in-memory C API](https://github.com/tesseract-ocr/tesseract/blob/5.5.3/include/tesseract/capi.h), [synchronous model loading](https://github.com/tesseract-ocr/tesseract/blob/5.5.3/src/api/baseapi.cpp) and [tessdata](https://github.com/tesseract-ocr/tessdata): native verifier/language-pack provenance; Windows model bytes avoid narrow native path parsing without changing recognition policy.
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR), [official Paddle model organization](https://huggingface.co/PaddlePaddle) and [llama.cpp](https://github.com/ggml-org/llama.cpp): model metadata/CTC and optional local visual retry. Manifest immutable revisions/hashes are authoritative for artifact identity.
- [cargo-llvm-cov 0.9.1](https://github.com/taiki-e/cargo-llvm-cov/tree/v0.9.1), [cargo-mutants 27.1](https://github.com/sourcefrog/cargo-mutants/tree/v27.1.0), [Miri](https://github.com/rust-lang/miri): bounded source-coverage/assertion-strength/runtime analysis.
- [RustSec](https://github.com/rustsec/rustsec), [cargo-deny 0.20.2](https://github.com/EmbarkStudios/cargo-deny/tree/0.20.2), [CodeQL](https://docs.github.com/en/code-security/code-scanning/introduction-to-code-scanning/about-code-scanning-with-codeql): dependency/license/source checks, never exhaustive security assurance.

- [Tauri CLI2.12.3 icon source](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.12.3/crates/tauri-cli/src/icon.rs) and [icon documentation](https://v2.tauri.app/develop/icons/): square transparent SVG/PNG input, native container generation and alpha-aware resizing. - [WCAG2.2 contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) and [reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html): measured contrast and reachable narrow/zoomed workspace controls.
- [ort rc.14 session options](https://github.com/pykeio/ort/blob/1ee1f842e8a381153ede7a506f01734e545854e0/src/session/builder/impl_options.rs), [CPU-selection regression](https://github.com/pykeio/ort/issues/662) and [ORT1.31 provider policy](https://github.com/microsoft/onnxruntime/blob/402979ac1bef89dcd55add41eaa7277c407599eb/onnxruntime/core/session/provider_policy_context.cc): the default efficiency policy can select CoreML; CPU registration alone does not override it. Explicit CPU policy and actual executed-node profiles are required before calling a result CPU evidence.
- [Microsoft runtime redistribution](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files?view=msvc-170): app-local files require applicable licensed-user rights and terms. Byte-preserving notice staging does not establish redistribution rights or platform signing.
- [Exact Tauri2.12.4 startup ordering](https://github.com/tauri-apps/tauri/blob/59b63ab500da9859f12d8888c3298bc29bba0b92/crates/tauri/src/app.rs#L2688-L2700): native webviews are created before user setup. Startup evidence must cover that boundary instead of treating a later Host log as the first possible progress.
