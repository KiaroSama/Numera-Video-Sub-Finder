## Confirmed findings and complete corrections

### N26-UI01 — About permits background application shortcuts

**Impact:** With a removable region selected, open Help > About and press Delete while its Close button is focused. The global window listener maps Delete and calls `remove_selected_region` although the native modal is open. The same boundary permits range marks, frame navigation, history commands and F1 opening another dialog. Native modal focus/inertness does not stop a focused dialog child's keyboard event from bubbling to a window listener. Existing dirty-review and native-operation checks still apply; no unsaved-project data-loss bypass is alleged.

**Root cause:** `app.rs` keeps About in its own signal while `hotkeys.rs` only recognizes Close and Shortcuts by name. Adding a modal bypasses this duplicated command-admission policy.

**Correction:** Extend modal admission at the global dispatcher using actual open studio dialogs. Preserve the existing native-close guard, ordinary dialog control activation, native Escape/cancel, and F1 closing the Shortcuts dialog. Block background application actions while About or another studio modal owns the interaction. Do not implement an About-only delayed workaround.

**Acceptance:** The hosted GUI witness opens the actual About control with an editable selected region, delivers cancelable keyboard events to the focused dialog control, and verifies unchanged region/time/source state plus no nested Shortcuts. Closing must restore normal command behavior. Existing close-lock, dirty Review, transport and Shortcuts witnesses remain. Programmatic key delivery is labelled honestly and does not qualify physical keyboard/IME input.

### N26-UI02 — Enter opens a menu without entering its items

**Impact:** Enter on a top-level menu trigger falls through to a native button click that only toggles visibility. Focus stays on the trigger; submenu items have `tabindex=-1`; Tab closes the menu. A second Enter closes it. ArrowDown works, but the declared menubar interaction is incomplete.

**Correction:** Handle unmodified Enter/Space only when the target is a top-level trigger, open that menu, defer first-enabled-item focus until the reactive update, and cancel the button's default toggle. Preserve item activation, modifier/composition guards, arrows, wrap, Escape, Tab and pointer behavior.

**Acceptance:** Verify actual trigger focus, expanded state, first enabled item after Enter/Space, enabled-item movement/wrap, Escape restoration and one ordinary action. Keep the current ArrowRight and pointer checks. Do not claim physical Tab traversal from synthetic events.

### N26-UI03 — Menu chrome obscures the focused skip link

**Impact:** The focused fixed skip link starts at y=8 with `z-index:4`; the new 32px menu row has `z-index:20`. Its center lies behind chrome, so the focused keyboard affordance is partly hidden.

**Correction:** Put the existing skip link at a documented stacking level above the menu (30 versus 20), retaining its existing main-landmark destination and focus handling.

**Acceptance:** Focus the real link, verify viewport bounds and `elementFromPoint` at interior positions, and activate its existing target. Keep actual layout/overflow checks. This verifies paint/focus behavior, not physical Tab input.

### N26-UI04 — Hover color violates the existing text-contrast floor

**Impact:** Both themes use white text on `#D44A4A` for primary hover, giving **4.305216:1**, below the existing **4.5:1** normal-size text contract. Normal `#C63D3D` and pressed `#AF3333` pass. The current visual witness checks only normal accent.

**Correction:** Change only hover to `#CB4242` (**4.775704:1** with white), preserving the red Graphite palette. Extend rendered-theme observations and their receipt to normal, hover and pressed colors; compare unrounded values against the unchanged floor. Retain source-pixel identity, logo, text/control contrast and frame filter/opacity assertions.

**Acceptance:** Both rendered themes must meet 4.5:1 for all three primary states. A computed token check must be described as such; it does not imply a physical-pointer hover test.

### N26-CI01 — Root aggregate can report success after announcement failure

**Correction:** Bind `ANNOUNCE` to the actual dependency result, require it to equal `success` before overall success, and retain its value in failure diagnostics. Keep every existing lane, child count, context name, source binding and timeout. No automatic trigger or copied status is introduced.

**Acceptance:** Static review must include successful children with failed/skipped/cancelled announcement, and normal hosted verification must retain all 15 successful jobs and 14 exact-head statuses. Do not falsely describe a negative runtime injection if only the predicate was inspected.
